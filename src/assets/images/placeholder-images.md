# Placeholder Images Needed

Please add these images to the `src/assets/images/` folder:

## Required Images:

1. **splash_img.png**

   - Size: 1080x1920px (or similar aspect ratio)
   - Purpose: Splash screen background
   - Should be a healthcare-related image

2. **onboarding-1.png**

   - Size: 400x300px
   - Purpose: First onboarding slide
   - Should show: Doctor with tablet (as shown in your design)

3. **onboarding-2.png**

   - Size: 400x300px
   - Purpose: Second onboarding slide
   - Should show: Doctor with headset (as shown in your design)

4. **onboarding-3.png**

   - Size: 400x300px
   - Purpose: Third onboarding slide
   - Should show: Doctor waving (as shown in your design)

5. **welcome-doctors.png**
   - Size: 400x300px
   - Purpose: Welcome screen
   - Should show: Collage of diverse doctors (as shown in your design)

## Optional Images:

- **logo.png** - App logo (512x512px)
- **placeholder.png** - Default placeholder image
- **avatar-placeholder.png** - Default user avatar

## How to Add Images:

1. Copy your image files to `src/assets/images/`
2. The app will automatically detect them
3. No need to modify any code - they're already referenced in `imageUtils.js`

## Testing Without Images:

If you don't have the images yet, the app will show placeholder content and won't crash. You can still test the navigation flow and UI structure.
